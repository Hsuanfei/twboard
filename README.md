# 台股戰略產生器 0928a

Powered by 黃炫斐(Mick Huang)

## 啟動

安裝 Python 3.10 以上後，雙擊「啟動.bat」，使用 Edge 或 Chrome。請先關閉舊版伺服器，並確認網頁抬頭為「台股戰略產生器0928a版」。如需兩版並行，可執行 `啟動.bat --port 8900`。

## 本版更新（0928a：K 線型態、籌碼成本分佈、族群輪動圖表、操作更友善）

**主K線圖（第 01 格）改成整列寬的大圖：**

- **區間切換**：近 60／120／250 日或跟「分析天數」相同，預設近 120 日。均線與布林通道在完整歷史上計算，切到 250 日時前段也不會空白；費波南希的波段跟著區間走。
- **K 線型態標註**：自動標出多頭吞噬、空頭吞噬、晨星、暮星、十字線、錘子線、吊人線、流星線、紅三兵、黑三鴉，▲ 紅色是看漲、▼ 綠色是看跌、◆ 黃色是中性；上方勾選列可以只留想看的型態。
- **跳空缺口**：向上（紅）／向下（綠）虛線框，延伸到價格回補為止。
- **頭肩頂／頭肩底**：畫出左肩、頭、右肩與黃色虛線頸線，✓＝收盤已突破／跌破頸線、？＝還在等待確認。
- **歷史勝率**：滑鼠移到標記，會顯示這檔股票過去（最多近 10 年）出現同一型態之後的「5／10 日上漲機率、樣本數 n、平均報酬」，並附上「全部交易日」的對照基準；「符號說明與這檔股票的歷史勝率」可展開整張表。第一次分析一檔股票時，會多抓一次近 10 年的日K（FinMind，只抓股價），之後每天只補新的一天；證交所來源用已抓到的期間統計。
- **籌碼成本分佈**：圖右側依價位加總的成交量（紅＝收紅K的量、綠＝收黑K的量），標出 POC 最大量價位（黃色虛線）與涵蓋 70% 成交量的價值區（淺藍色帶；上緣 VAH 壓力帶、下緣 VAL 支撐帶）。用滾輪縮放 K 棒時，會用看得到的那一段重新計算。
- 圖下方多了一段白話摘要（區間內多空型態次數、最近一次型態、頭肩與未回補缺口、收盤在價值區的哪一側）。
- 為了圖面清楚，布林通道與費波南希改為**預設關閉**（按鈕一按就開）；所有開關、區間、型態勾選都記在這台電腦的瀏覽器。離線匯出的報告也能切換。

**族群輪動（市場掃描）：**

- 五種圖表：**四象限雷達**（泡泡大小改成成交值，🔔＝3 日內剛換象限、黃框＝動能加速，點泡泡畫出最近 10 天的移動軌跡）、**強弱熱力矩陣**（最近 20 個交易日，可切換當日漲跌／5 日報酬／相對大盤）、**排名變化**、**象限時間軸**、**動能加速度**。族群表多了「加速度」欄與象限轉換提示。
- **自訂族群編輯器**：每列一個族群，成分股用逗號分隔，只填代號也可以（自動帶入名稱，也接受「3661 世芯-KY」這種寫法）；可以**匯出／匯入 JSON** 備份或分享，「還原預設」要按兩次確認。預設範例新增 IC 設計、半導體設備、網通、面板、綠能、汽車／電動車 6 個族群。

**操作更友善：**

- 往下捲動時，上方出現精簡頁首：可以直接輸入代號分析、看目前股票的價格，並一鍵跳到圖表、比較表、市場掃描、全球市場或回到頂端。
- 按「產生圖表」後，第一檔畫好就自動捲到結果；全球市場面板也可以收合（記住設定）。
- 首頁改成「三個步驟開始」的說明；名詞解釋新增「K 線型態與籌碼分佈」一類（12 項）與族群輪動 5 項，共 95 項。
