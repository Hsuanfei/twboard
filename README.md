# 台股戰略產生器 20260925c

Powered by 黃炫斐(Mick Huang)

## 啟動

安裝 Python 3.10 以上後，雙擊「啟動.bat」，使用 Edge 或 Chrome。請先關閉舊版伺服器，並確認網頁抬頭為「台股戰略產生器20260925c版」。如需兩版並行，可執行 `啟動.bat --port 8900`。

## 本版更新（20260925c：日經 225 可改用 Yahoo 財經）

- **Yahoo 財經備援（選用，預設關閉）**：進階設定新增「美、日指數取不到時，改用 Yahoo 財經」。勾選後，日經 225、S&P 500、那斯達克在 FinMind 與 Stooq 都沒有新資料（取不到或落後超過 7 天）時，才改查 Yahoo 財經，小卡來源標示「Yahoo 財經（非官方）」。一個序列只用一個來源，不拼接。
- **注意**：Yahoo 財經沒有官方 API，這是網站本身使用的網址，可能改版或限流（HTTP 429），資料條款僅限個人使用；分享給別人的版本預設不會使用。還在交易中的當天 K 棒不採用，避免把盤中價當成收盤存進快取。
- 勾選後按「連線檢查」也會多檢查 Yahoo 財經一項。

## 20260925b 更新（修正證交所／櫃買連不上）

- **連線修正**：Python 3.13 起預設開啟 X.509「嚴格模式」，證交所與櫃買中心的憑證缺少嚴格模式要求的欄位，程式會出現「取得失敗（URLError）」而完全抓不到上市櫃資料（瀏覽器不受影響）。本版關閉這個嚴格模式，憑證鏈與網址仍照常驗證。這也影響「證交所 TWSE」資料來源的個股分析。
- **看得懂的錯誤原因**：命令列視窗與畫面改為顯示實際原因，例如「SSL 憑證驗證失敗（…）」「找不到主機」「連線被中斷」，連不上的網站在同一次掃描中不再重試，幾秒內就會結束。
- **連線檢查**：市場掃描右上角新增「連線檢查」按鈕，掃描失敗時也會自動執行：逐一測試證交所、櫃買（新舊網址）、FinMind，列出結果、HTTP 狀態、Python／OpenSSL 版本與可能原因。

## 20260925a 更新（市場掃描）

全球市場面板下方新增「市場掃描」，一次看上市櫃全部股票，結果都是股票代號清單，點代號就載入 18 格分析：

- **選股清單**：綜合強勢、放量突破、站上月線、創 60 日新高、法人連買、投信連買、跌深反彈、強勢族群領頭，共 8 份清單，每檔附上觸發的標記（法人連買 N 日、爆量、60 日新高…）。可勾選最多 10 檔一次比較。
- **漲幅排行**：今日漲幅、跌幅、成交值、量比、5 日與 20 日漲幅前 50 名。
- **熱門 ETF**：依成交值、漲跌、量比排序，標示債券、槓桿、反向、期貨型。
- **族群輪動**：5 日 × 20 日報酬四象限圖（領漲／轉強／轉弱／落後），泡泡大小是波動度，下方族群表有 5／20／60 日報酬與代表股，點族群看全部成員。族群包含官方產業別與可自行編輯的概念族群（AI 伺服器、CoWoS、散熱、矽智財…，預設為範例，存在 themes.json）。
- **到價警示**：設定上限價、下限價或單日漲跌幅，收盤後比對，有新觸發時分頁會出現紅色數字（alerts.json）。
- **模擬持倉**：記錄模擬買進／賣出，扣手續費與交易稅計算損益（portfolio.json）。18 格上方也有「模擬買進」「設定到價警示」按鈕。
- 名詞解釋新增 14 項說明（綜合強勢分、選股條件、族群象限、模擬損益的算法等）。

**第一次掃描要幾分鐘。** 資料是證交所、櫃買中心每天收盤後公布的全市場行情與三大法人，只能一天一天下載；為了不被擋，每個請求間隔約 2 秒。60 日期間第一次約 3～4 分鐘（20 日期間約 1～2 分鐘），之後每天只補新的一天，重新打開頁面時直接用本機快取顯示上次結果。產業別取自 FinMind 股票清單，取不到時只顯示概念族群。

**來源改版時。** 證交所、櫃買的網頁資料格式偶爾會改。程式依欄位名稱解析，櫃買新版網址失敗會自動改用舊版；還是看不懂時，會把回應開頭記在 `market_debug.log`（不含 Token），把這個檔案回報即可修正。所有清單都是規則篩選結果，不是投資建議。

## 20260924a 更新（指標名詞解釋）

- **右上角「指標名詞解釋」**：點頁首右上角的 ⓘ 按鈕，打開畫面上所有指標的說明，共 63 項、12 類。每一項分成「是什麼／怎麼算／怎麼看／要注意」，公式與程式實際的計算一致（例如 KD 的 1/3 平滑、綜合分 32/28/25/15 的權重、研判文字的判斷順序）。
- **圖卡速查**：點「06 KD 指標」「16 融資融券」「自選股比較表」等任一格，下方只留下那一格用到的名詞；也可以直接搜尋（中英文、不分大小寫）。
- **附上目前數值**：載入個股後，每一項會附上目前這一檔的數字，例如「K 45.7、D 39.6：KD 未達超買 / 超賣」，方便對照畫面。
- **離線報告也有**：下載的戰略報告 HTML 右上角同樣有這個按鈕，寄給別人也能查；列印時不會出現。手機版只顯示圖示、說明改為全螢幕。
- **修正**：多檔同時載入時，畫面固定先顯示輸入順序中的第一檔（0922c 會顯示最先下載完的那一檔）。
- 說明文字集中在新檔案 `glossary.js`，想修改或補充說明只要改這個檔案。指標與計分規則沒有變動，計分版本仍為 `0922b-directional-volume`。

## 0922c 更新（加速）

本版不改任何指標與計分規則，只把「等資料」的時間縮短：

- **多檔同時分析**：輸入多檔或開啟群組時，前端一次把所有代號送進伺服器，伺服器同時處理 4 檔（原本一檔做完才做下一檔，且同時超過 4 件就拒絕）。排隊上限 32 件，群組 8 檔不會再出現「目前載入工作較多」。
- **每檔的資料集平行抓**：股價與基本資料先一起抓，接著三大法人、融資融券、除權息、大盤基準四個一起抓；一檔的等待時間從「六次請求相加」變成「最慢的那一次」。全球面板的五個序列也同時抓。同時對外連線最多 8 條，多檔同時要大盤指數時只抓一次。
- **收盤資料不再反覆確認**：最近一個平日的資料已經到手，一天內就不再每 10～15 分鐘重查近 7 日（資料還沒出來時照舊每 15 分鐘確認一次，法人、融資券當天 22:00 前也照舊確認）。除權息改為一天確認一次。
- **部分缺漏不再整份重抓**：有警示（例如某個資料集暫時取不到）的結果改為短暫快取 2 分鐘再重試缺漏，原本是每次查詢都整份重抓；全球面板缺日經時同樣適用，不會每次開頁面都重抓五個序列。
- **快取檔案**：改用長期連線與 WAL 模式，減少每檔十多次的開檔與 fsync；連線逾時 30 秒×3 次改為 20 秒×2 次，來源沒回應時不會卡太久。

實測（模擬每次請求 0.4 秒延遲，8 檔）：全新快取 18.2 秒 → 2.1 秒；快取已有資料但過了確認間隔 15.0 秒 → 0.5 秒（不需任何請求）。實際速度仍受 FinMind 回應與配額影響；證交所 TWSE 來源因為要逐日查詢且有頻率限制，仍然較慢。

## 0922b 更新

- **量價評分修正**：成交活躍度另列，不直接加進總分。量價分依收盤相對前日的方向計算：50 ± 35 × min(量比/2,1)，上漲加、下跌減，平盤為 50。零成交量及必要資料缺漏不計分。量比仍採當日量／含當日的 20 日均量，權重維持 15%；其他分項缺漏時沿用原有的重新分配權重規則。
- **ADX／DMI（14 日）**：主圖區下方新增趨勢強度圖；＋DI、−DI 判斷方向，ADX 看強度。初始 DI 需 15 根 K 棒，初始 ADX 需 28 根；資料異常重新暖身，缺值不補零。完全無波動時 DI／ADX 為 0。ADX <20、20～25、≥25 是可讀性分區，並非獲利保證；本版不把 ADX 加入總分。
- **比較表與篩選**：增加 ADX、＋DI、−DI、量價方向，以及最低 ADX 與 DMI 方向篩選，可與布林條件併用、儲存及匯出。股價 CSV、原始資料表及批次總覽也包含新指標。
- **RSI 平盤處理**：全程價格不變時採中性 50，不標成 100。
- **全球市場資料**：美元兌台幣只用台銀即期買賣中價，不以現金牌告替代。檢查日期、數值與報價順序，使用新快取鍵避免混入舊口徑。美／日指數主來源空白或日期較舊時檢查備援；只選一個來源，不拼接兩種來源計算漲跌。顯示資料來源、日期與較舊提示；日期差是日曆天，並非缺少的交易日數。
- **更新與匯出**：按市場「更新」會重查近期 7 日並補缺日，既有較早快取繼續使用。匯出 HTML 固定帶入目前畫面所見的市場快照，不會拿其他視窗後來的更新替換；快照過期時需先更新面板。1／5／20 日變動各依市場自己的觀測日計算，不是假日補值；各指數起點＝100 的基準日可能不同，不直接作同期績效排名。
- **操作一致**：全球指數、匯率、ADX 圖均可點擊放大、再次點擊縮回，支援 Esc；全球面板在尚未查詢個股時也可放大。字體大小變更會同步重畫全球圖表。下載的離線報告同樣可操作。

計分版本為 `0922b-directional-volume`。歷史回測逐日使用新版相同規則，新舊版的綜合分不能直接混合比較。OBV、ATR 移動停損、週線確認與手動費波南希錨點尚未加入。

## 資料來源驗證與限制

本次以公開歷史區間 2024-09-02～2024-09-06 做連線驗證：FinMind 的 S&P 500、那斯達克均取得 4 筆；日經 225 在測試當下的兩個來源未取得資料，因此維持「無資料」，沒有用估計值替代。這不代表目前即時行情或所有日期均已驗證。來源可用性、資料日期、配額及網路狀態仍以畫面提示為準。

個股資料依 FinMind／證交所來源可用性取得；價格未還原，除權息可能影響技術指標。交易模擬持倉跨除權息而缺少還原資料時仍暫停顯示資金績效。

## 檔案與資料夾

原始碼：https://github.com/Hsuanfei/twboard 。分享用的壓縮檔（例如 `台股戰略產生器20260925c.zip`）只附執行程式、圖表資源、啟動工具、本說明與必要授權文件；GitHub 上另含測試程式。兩者都不含測試截圖、舊版備份或歷史行情快取。首次查詢會重新建立 `.twboard-cache`，自選群組與篩選條件在操作儲存後分別建立 `watchlists.json` 與 `filter_presets.json`；批次報告存於 `reports`。若有舊設定可自行複製上述兩個 JSON，舊篩選缺少 ADX 欄位時視為不限。20260924a 起多了 `glossary.js`（指標名詞解釋），20260925a 起多了 `twmarket.py` 與 `market.js`（市場掃描），更新或分享時要和其他檔案放在同一個資料夾，缺少時程式會提示找不到檔案。市場掃描使用時會另外建立 `themes.json`（自訂概念族群）、`alerts.json`（到價警示）、`portfolio.json`（模擬持倉），來源格式有問題時會建立 `market_debug.log`。

「每日批次.bat」讀取已儲存群組，產生個股離線 HTML、總覽 index.html 與 summary.csv；它仍輸出全部指定股票，不自動套用互動頁的篩選。Excel 匯入 CSV 時把代號欄設為文字，可保留 0050 等前導零。

## 開發與測試

- Python 單元測試（不需連網，用模擬資料）：在專案資料夾執行 `python -m unittest`。
- 瀏覽器測試：需要 Node.js 與 Playwright（`npm install playwright`），逐一執行 `node test_browser_*.js`。Python、Playwright 與瀏覽器的位置可用環境變數 `TWBOARD_TEST_PYTHON`、`TWBOARD_TEST_PLAYWRIGHT`、`TWBOARD_TEST_CHROMIUM` 指定，或寫在不進版控的 `test_local.json`。
- 程式只用 Python 標準函式庫，不需要 `pip install`。
